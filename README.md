# Ionut-Marius Dutan Website

Personal portfolio website for GitHub Pages.

Publish this repository as `ionutmariusdutan.github.io` to make it available at:

https://ionutmariusdutan.github.io

## Languages

The site opens in English. The EN/RO button in the top bar switches to Romanian (`?lang=ro` opens it directly).
Romanian text lives in `i18n.js`, keyed by the exact English text in `index.html`. When English text changes,
update the matching key there, otherwise that line stays in English in Romanian mode.
The "View CV" button opens `assets/Ionut-Marius-Dutan-CV-2026-RO.pdf` in Romanian mode.
